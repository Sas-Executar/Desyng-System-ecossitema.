# HANDOFF — Pack Visual App + Blog

## Conteúdo do pacote
- 10 slides em PNG no formato 16:9.
- 1 master index em CSV para rastreio e handoff.
- Arquivos nomeados com prefixo numérico para manter a ordem do deck.

## Estrutura
- `slides/` → assets finais do deck.
- `MASTER_INDEX.csv` → índice mestre com ID, título, caminho e status.
- `00_README_HANDOFF.md` → instruções rápidas de uso.
